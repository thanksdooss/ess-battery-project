# 데이터 규칙 (모든 분석·모델링 공통)

`src/data.py` 가 이 규칙을 구현한다. 근거는 원본 `.mat` 파일을 직접 확인한 결과.

## 배치 정의 (노션 표 그대로)

| 배치 | 파일 | 노션 활용 | 셀 수 | 수명 라벨 있음 | 중도절단 | 라벨 NaN |
|---|---|---|---|---|---|---|
| Batch 1 | 2017-05-12 (2.8GB) | 원논문의 학습 데이터셋 | 46 | 36 | 10 | 0 |
| Batch 2 | 2018-02-20 (1.9GB) | 원논문의 1차 테스트셋 | 47 | 39 | 0 | 8 |
| Batch 3 | 2018-04-12 (3.0GB) | 원논문의 2차 테스트셋 | 46 | 44 | 0 | 2 |
| extra | 2018-04-03 varcharge (0.1GB) | 충전 최적화 실험용 (Attia 2020) | — | 사용 안 함 | | |

- '활용' 열은 노션 표기다. (아래 원저자 코드 관련 내용은 모두 Batch 2 Test 실행 뒤에 확인했다.) 원논문 Methods·원저자 공개 코드(LoadData.m)가 쓴 배치는 2017-05-12·2017-06-30·2018-04-12다.
  1차 테스트셋(43셀)은 2017-05-12·2017-06-30 셀을 학습(41셀)과 번갈아 나눈 것이고, 2018-02-20(이 저장소의 Batch 2)은 원저자 코드에 쓰이지 않았다.
  2018-04-12(Batch 3)는 원논문 2차 테스트셋이다.

## 사이클 번호
- `summary` 의 k번째 행 = cycle k+1 (`summary['cycle']` 이 1부터 시작).
- `Qdlin` / `Tdlin` / `discharge_dQdV` 의 k번째 행 = summary 의 k번째 행과 같은 사이클.
- 따라서 노션의 "사이클 100번 − 사이클 10번" ΔQ(V) = `Qdlin[99] − Qdlin[9]` (`data.delta_q`).
- Batch 1 의 cycle 1 은 비어 있는 더미(QD=0, Qdlin 없음).

## 수명 라벨 (`cycle_life`)
- EOL = 정격 1.1 Ah 의 80% = **0.88 Ah** (노션: "EOL(80% SOH 도달)").
- Batch 1·3 은 EOL 직전에 기록이 끝나 `cycle_life = 기록된 사이클 수 + 1`. Batch 2 는 EOL 이후(약 0.825 Ah)까지 계속 측정했고 `cycle_life` = QD 가 처음 0.88 Ah 미만이 된 사이클.
- **중도절단(censored)**: 라벨은 있지만 기록 종료 시 아직 EOL 미도달(마지막 20 사이클 QD 최솟값 > 0.885 Ah). Batch 1 의 00·01·02·03·04·08·10·12·13·22 (10개). 이 값은 실제 수명의 하한값이라 학습 타깃에서 제외한다(원저자 공개 코드 Load Data.ipynb 도 08·10·12·13·22를 80% 미도달로 지운다. 00\~04 는 원저자가 2017-06-30 파일의 이어진 기록을 붙여 수명을 확정했지만, 과제 데이터에는 그 파일이 없다).
- **Batch 3 원저자 제거 셀** (테스트 뒤 확인, DAY 1 기록의 #38·#39 목록을 정정): 원저자 공개 코드는 Batch 3 에서 02·23·32·37·42·43 을 지운다(키 b3cN 의 N = .mat 순서 = 이 저장소 idx). 23·32 는 EOL 미도달(라벨 없음), 02·37·42·43 은 품질 문제로 보인다(LoadData.m 주석: #37 데이터 수집 문제, #02·#42·#43 잡음. 논문은 셀 번호를 적지 않았다). 평가에서는 포함/제외를 함께 보고한다(`src/train.py` `B3_PAPER_REMOVED`).
- **라벨 NaN**: Batch 2 의 VarCharge 4개·SLOWCYCLE 4개(수명 시험이 아닌 별도 프로토콜), Batch 3 의 23·32(2,189·2,237 사이클까지 EOL 미도달).
- 지도학습에 쓰는 셀 = `labeled` (라벨 있음 & 중도절단 아님).

## 충전 프로토콜
- 그룹: `fastcharge`(일반 "C1(Q1%)-C2"), `newstructure`(이름에 -newstructure), `varcharge`, `slowcycle`.
- Batch 1 = fastcharge 46개, Batch 2 = fastcharge 30 + newstructure 9 + varcharge 4 + slowcycle 4, Batch 3 = newstructure 46개.
- 노션 정의("Q1%까지 C1, 이후 C2")로 0→80% 충전시간 `t80_min` 과 평균 C-rate `avgC_80` 계산 (`data.parse_policy`).

## 측정 오류 처리 (`data.clean_summary`)
행은 지우지 않고(사이클 번호 유지) 값만 NaN 으로 바꾼다.
- QD/QC ≤ 0 또는 > 1.2 Ah, IR ≤ 0, chargetime ≤ 0 또는 > 100분, 온도 ≤ 0.
- Batch 2 의 40\~46번 셀은 IR 이 전 사이클 0 (측정 누락).

## 재현성
- `RANDOM_STATE = 42` 를 모든 분할·모델에 사용(반복 외부 CV 20회는 seed 42\~61).
- 라이브러리 버전은 `requirements.txt` 에 고정.
